# Nano-PKPD

## Manuscript title: Analysis of Pharmacokinetic-Pharmacodynamic Relationships of Nanoparticles Against Tumors

**Manuscript status:** Under review

**Last Updated:** February 10, 2026  

---
## 📘 Overview

- This repository provides the curated datasets and model codes for establishing relationships between Nanoparticle PK and antitumor PD efficacy.

- The Nano-PKPD Database will be published as Supplementary Material of the article. 

---

## 📂 Repository Structure

### **AI for Nano PKPD**
- df_ML.csv: the used data for ML/AI development.
- AI_for_Nano_PKPD.ipynb: ML/AI model code for the investigation of Nano PK-PD relationship, including data preprocessinng, ML/AI development, hyperparmeter tuning, and feature importance analysis. 

## 🌟 Key Features

- **Comprehensive features** Nanoparticles' physicochemial properties, experimental strategies, administration regimens were collected from the published papers. 

- **Exploration of PK-PD relationship** To establish the PK/PD relationship, the PK metrics were predicted by the AI-assisted PBPK model, informing ML model development. 

- **Interpretation** SHAP analysis was applied to explain the feature importance on model predictions.
